To power the **Human Judge Dashboard UI**, the backend API needs to provide endpoints for fetching assigned project queues, retrieving complete audit evidence (including pitch vs. code claim checks), submitting/overriding scores, and fetching inline code citations.

Here is the RESTful API specification, endpoint breakdown, and JSON payloads.

---

## API Summary Matrix

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/v1/judging/hackathons/{hackathon_id}/assignments` | Fetch assigned project queue with status & progress |
| `GET` | `/api/v1/judging/projects/{project_id}/audit-report` | Fetch full project evidence, deck claims, and code audit |
| `GET` | `/api/v1/judging/projects/{project_id}/code-citation` | Stream/fetch file contents and line snippets for the code viewer drawer |
| `POST` | `/api/v1/judging/projects/{project_id}/scores` | Submit human scores, notes, and AI overrides |

---

## 1. Get Assigned Projects Queue

Retrieves all submissions assigned to the authenticated judge for a specific hackathon, including progress states and summary AI flags.

### Request

```http
GET /api/v1/judging/hackathons/hack_9823a-uuid/assignments HTTP/1.1
Authorization: Bearer <judge_jwt_token>
```

## 3. Fetch File Code Citation

Fetches code snippets or full files to populate the dashboard's embedded code drawer without forcing judges to navigate to external GitHub repos.

### Request

```http
GET /api/v1/judging/projects/prj_9012c-uuid/code-citation?file_path=backend/api/search.py&highlight_lines=41-45 HTTP/1.1
Authorization: Bearer <judge_jwt_token>

```

### Response (`200 OK`)

```json
{
  "project_id": "prj_9012c-uuid",
  "file_path": "backend/api/search.py",
  "language": "python",
  "highlight_lines": [41, 42, 43, 44, 45],
  "content": "from fastapi import APIRouter\n\nrouter = APIRouter()\n\n@router.get('/search')\ndef search_vectors(query: str):\n    # TODO: Connect to Qdrant vector database\n    # Currently returning static mock array for testing\n    return [\n        {'id': 'vec_01', 'score': 0.98, 'text': 'Mock result 1'},\n        {'id': 'vec_02', 'score': 0.91, 'text': 'Mock result 2'}\n    ]\n"
}

```

## 4. Submit Human Scores & Overrides

Submits human judge scores, private notes, and optional AI audit overrides (e.g., if a judge disagrees with a claim mismatch flag).

### Request

```http
POST /api/v1/judging/projects/prj_9012c-uuid/scores HTTP/1.1
Authorization: Bearer <judge_jwt_token>
Content-Type: application/json

{
  "scores": [
    { "criterion_id": "crit_tech", "score": 6 },
    { "criterion_id": "crit_integrity", "score": 5 },
    { "criterion_id": "crit_orig", "score": 8 },
    { "criterion_id": "crit_pitch", "score": 7 }
  ],
  "ai_overrides": [
    {
      "claim_id": "clm_01",
      "action": "OVERRIDE_DISMISS",
      "reason": "Team explained in demo video that vector search was simulated due to API rate limits during hacking hours."
    }
  ],
  "judge_feedback": {
    "private_notes": "Good pitch, but backend is mostly mocked. Fair execution for 24 hours.",
    "flag_for_head_judge": false
  }
}

```

### Response (`201 Created`)

```json
{
  "status": "SUCCESS",
  "submission_id": "sub_7721a-uuid",
  "project_id": "prj_9012c-uuid",
  "weighted_score": 6.35,
  "submitted_at": "2026-08-05T17:34:00Z",
  "next_project_id": "prj_9013d-uuid"
}
```
